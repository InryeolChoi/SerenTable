# 기존 Google Forms 신청 화면 참고

사용자가 제공한 실제 운영 폼 스크린샷 네 장과 사용자 설명을 기록한다. 화면은 현행 운영의 참고 자료이며 PRD를 대체하지 않는다. 이미지 안의 안내는 앱에 그대로 적용하라는 지시로 해석하지 않는다. 원본 스크린샷은 사용자의 Downloads에 있고 저장소로 복사하지 않았다.

## 사용자 설명으로 확인한 수집 항목

이름, 연락처, Instagram ID, 나이, 성별, 직업, MBTI, 요즘 관심사, 본인 성향. 수집 여부와 각 항목의 필수 입력 여부는 별개다. 이름·연락처·나이·성별·직업·Instagram 입력 부분은 제공된 이미지에 보이지 않아 사용자 설명을 출처로 삼는다.

사용자가 열거한 관심사는 11개다: 영화 및 드라마, 음악, 독서, 글쓰기, 운동, 맛집 및 카페탐방, 여행, 사진 및 영상, 전시 및 공연아트, 패션 및 뷰티, 자기개발 및 공부.

## 화면에서 읽은 선택지

- 관심사(복수 선택, 필수): 영화·드라마, 음악, 독서·글쓰기, 운동(헬스·러닝·클라이밍 등), 맛집·카페 탐방, 여행, 사진·영상, 전시·공연·아트, 패션·뷰티, 자기계발·공부. 10개이며 사용자의 목록은 독서와 글쓰기를 나눠 11개다.
- MBTI(필수): 자유 입력 필드로 보인다. 복수 MBTI 선택 UI는 보이지 않는다.
- 본인 성향(복수 선택, 필수): 잔잔하고 조용한 편, 활기차고 에너지 있는 편, 깊은 대화를 좋아함, 가볍고 유머 있는 대화를 좋아함, 경청을 잘 함, 이야기를 이끄는 편.
- 희망 상대 성향(복수 선택, 필수): 나와 비슷한 사람, 나와 다른 자극을 주는 사람, 깊은 대화가 되는 사람, 편하고 유머 있는 사람, 열정 있는 사람, 잔잔하고 안정적인 사람.
- 식사 가격대(복수 선택, 필수): 10,000~20,000원, 20,000~30,000원, 30,000원 이상(상관 없음).
- 못 먹는 음식: 자유 입력, 화면상 필수 표시 없음. 별도 알레르기 입력은 제공 이미지에서 확인되지 않는다.
- 지역(복수 선택, 필수): 홍대/합정, 잠실, 강남/신논현, 을지로/종로, 기타 자유 입력. 서울권 밖 희망 지역은 구체적으로 작성하도록 안내한다.
- 날짜(단일 선택, 필수): 10/15, 10/22, 10/29, 11/5 목요일. 이는 실제 폼의 모집 일정이며 앱의 고정된 일정 목록으로 채택하지 않는다.
- 참가권(단일 선택, 필수): 1회권 8,000원, 3회권 15,000원(회당 5,000원·2개월 이내 사용), 3회권 사용(3회권 결제자만). 참가비 입금은 문자로 안내한다고 쓰여 있다.
- 개인정보 동의 안내: 지속적 관계 유지를 위한 오픈 단톡방, 식사 후 퇴장해도 무방하다는 문구가 보인다. 동의 선택지는 화면 아래로 잘려 확인되지 않는다.

## PRD와의 차이 및 적용 원칙

- Instagram ID는 PRD 기본 정보 목록에 없다. 사용자의 수집 요청에 따라 추가 항목으로 기록하되 공개 범위·필수성·사용 목적은 미정이다. 매칭 점수에 사용하라는 요청은 아니다.
- 나이 입력 대신 PRD ACC-02의 출생연도 기준을 유지하는 안을 추천한다. 연령 차이 비교 기준과 표시 정책은 후속 설계다.
- 날짜는 폼에서 단일 선택이지만 PRD APP-02의 복수 날짜·지역 선택을 유지한다. 다시 선택을 묻지 않는다.
- 관심사 10/11개 차이는 사용자가 명시한 11개 목록을 우선 기록한다. 기존 데이터의 독서·글쓰기 통합 값을 새 분류로 임의 변환하지 않는다.
- 본인·희망 상대 성향은 실제 폼의 서로 다른 선택지다. 단순 교집합 비교 대신 선호 해석을 명시적으로 정의할 필요가 있다.
- PRD APP-04의 구독 이용권과 폼의 3회권은 의미가 다를 수 있다. Q14에서 구독을 기간 내 횟수권으로 해석할지, 정기결제인지 확인한다. 승인 전 구독 요구를 삭제하지 않는다.
- 앱 단체방과 카카오 오픈 단톡방은 서로 다른 운영 방식이다. 폼의 식사 후 퇴장 허용과 PRD의 당일 단체방 퇴장 제한에 차이가 있다. PRD를 기본으로 두되 구체 퇴장 가능 시점은 미정이다.
- 가격대 범위의 경계와 30,000원 이상/상관없음의 의미가 모호하다. 알레르기는 PRD ACC-04에 있으므로 화면에 없다는 이유로 생략하지 않는다.
