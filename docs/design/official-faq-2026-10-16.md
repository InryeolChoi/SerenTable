**수신·기록일:** 2026-10-16, Asia/Seoul. 사용자가 대화로 전달한 Blaybus 개발 2일차 안내와 과제 FAQ를 정리했다. 공지 원문 URL과 별도 개정 번호는 제공되지 않았으며 웹에서 직접 확인한 기록은 아니다.

**업무 위치:** 개발·배포 기반 확보 → 요구사항·설계·자료 정리 → 기술 결정 및 미결정 항목 정리 / PRD·구글폼·킥오프 차이 기록의 보강. 새 Task를 추가하거나 제품 구현 완료로 처리하지 않는다.

## 프로젝트 기록과 제출

- Blaybus Workspace 기록은 프로젝트 기록 평가 10점에 반영된다.
- 상단 목표에 10/15~10/21 동안 만들 결과물과 기간을 적는다.
- 계획은 Agenda → Work → Task로 나눈다.
- 작업 시작·중단 때 같은 Task의 타이머를 켜고 끈다. 이어서 하는 작업은 Task를 새로 만들지 않고 같은 Task에서 타이머를 다시 켠다.
- 타이머 종료와 Task 완료는 별개다. 작업 완료 후 완료 버튼을 직접 누른다. 에이전트는 실제 투입 시간을 추정하지 않는다.
- 10/21(수) 23:59까지 프로그램 제출탭에 배포 링크와 테스트 계정을 제출한다.

## 과제 FAQ: 확정된 안내와 허용 범위

| 공식 FAQ | 전달된 답변의 의미 |
|---|---|
| 앱 Q1 | 참가자 화면은 별도 설치 없는 모바일 웹앱으로 배포하고 링크로 심사한다. |
| Q1 환불 시각 | 현행 운영은 화요일 자정(24:00) 이후 환불 불가. 매칭 마감과 같은 시각을 쓸지는 개발자가 결정한다. 화요일 24:00는 수요일 00:00와 같은 경계다. 회차별 적용·다른 요일 행사·시스템 실패 환불 예외는 별도로 정해야 한다. |
| Q2 당일 취소 | 앱에서 차단하거나 접수 후 이용 제한 대상으로 처리하는 방식은 PRD §7.3·§15 원칙 안에서 개발자가 정한다. |
| Q3 노쇼 | 횟수·제한 종류·자동/운영자 처리·이용권 차감 기준은 정해져 있지 않다. PRD SAF-02·§15 안에서 정한다. |
| Q4 이용권 가격 | 1회권 9,900원. 멤버십 1개월 35,000원 / 3개월 75,000원 / 6개월 120,000원. 과거 폼의 8,000원·3회권 가격을 앱 가격으로 사용하지 않는다. |
| Q5 멤버십 | 유효 기간 안에 횟수 제한 없이 참여한다. 매칭에 실패하면 실패한 횟수만큼 이용 기한을 연장한다. 실패 1회당 연장 일수·중복 연장 방지·기산점은 답변에 없다. |
| Q6 확정 후 3명 | 구체 처리 기준은 개발자가 정하되 필수조건은 완화하지 않는다. 일정 이동·환불은 참가자 선택 원칙을 유지한다. 3인 테이블을 자동 허용하는 답변이 아니다. |
| Q7 성비 | 필수조건이 아닌 선호조건이다. 단일 성별·한 명만 다른 성별 구성의 허용 및 점수 반영은 개발자가 정한다. |
| Q8 MBTI | 공식 궁합 기준표는 없다. 궁합 기준은 개발자가 정한다. |
| Q9 지역·식당 | 현재 서울 홍대·잠실·강남·을지로 4개 지역 운영. 서울 외 지역은 향후 계획이며 앱 포함 여부는 개발자 판단이다. 식당은 리뷰 평점이 좋고 예약 가능한 곳을 기준으로 확보한다. 외부 예약 API 구현 의무를 새로 부여한 답변은 아니다. |
| Q10 참가 확정 | 운영자 사전 검토 없이 PRD대로 자동 확정한다. |
| Q11 운영 자료 | 문의·운영 기록 로그 파일은 제공하지 않는다. 해당 자료 수령을 개발 선행 조건으로 두지 않는다. 앱 자체 운영 로그는 별개다. |
| Q12 로고 | 원본 SVG·투명 PNG가 없으며 비슷하게 재현해 사용해도 된다. 공식 원본 수령을 기다리지 않는다. 재현물을 공식 원본으로 표시하지 않는다. |

## 기존 문서와의 관계·남은 결정

PRD를 기본 요구사항으로 유지하고 이 FAQ를 주최 측의 구체화·허용 범위로 함께 적용한다. 명시된 값과 개발자 재량을 구분하며 새 충돌은 별도로 기록한다.

- U03: 가격·상품 기간·기간 내 횟수 무제한·실패 시 연장 원칙은 해소. 연장 단위/기산점, 갱신·만료·환불 계산·보관/재사용은 미정이다. ‘실패 1회=1주 연장’이나 자동 갱신을 확정하지 않는다.
- U04: 화요일 24:00 기준을 기록했다. 매칭 마감과의 일치 여부, 회차별 적용, 시스템 사유 환불 예외, 당일 취소/단체방 퇴장은 미정이다.
- U05: 성비는 선호조건이고 공식 MBTI 표가 없다는 점이 명확해졌다. 실제 점수·허용 정책은 개발자 결정이 필요하다.
- U13/U16: 확정 후 인원 부족·노쇼 제한의 재량이 확인됐다. 구체 정책이 자동 확정된 것은 아니다.
- 현행 폼의 가격·지역 자유 입력은 운영 관찰 자료다. 앱 가격에는 FAQ Q4를 적용하며, 서울 외 지역 지원은 아직 승인하지 않았다.
- UI 브랜드 보완은 제공 자료를 참고해 재현할 수 있다. 현재 스케치의 브랜드 일치 또는 UI Task 완료를 증명하지는 않는다.
