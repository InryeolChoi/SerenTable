읽는 방법과 핵심 구분
  • Application: 한 번의 참여 의사, ApplicationCandidate: 동의한 날짜·시간·지역 후보입니다.
  • MatchParticipation: 회차별 처리 기록, TableAssignment: 실제 테이블 배치입니다.
  • 신청·결제·매칭·참석 상태는 분리합니다. 결제 완료가 테이블 확정을 뜻하지 않습니다.
  • 이동·환불·권리 사용의 경쟁, 4~6인·연령·제외 관계 조건은 그림만으로 보장되지 않습니다. 트랜잭션과 제약 책임은 설계 원문을 함께 확인합니다.
  • 그림은 설계 원문의 Mermaid 블록에서 생성했습니다. 변경 시 scripts/render_erd.py로 다시 생성합니다.
