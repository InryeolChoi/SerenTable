# ADR-0011 매칭 실험·정답 비교 기록 (2026-10-17)

[ADR-0011](../adr/0011-prd-matching-score-and-objective.md)의 운영 적용 전 확인 자료다. 결과는 같은 저장소 커밋의 `scripts/matching_experiments.py`와 `tests/oracle/test_engine_against_scoring_oracle.py`로 재현한다. **만족도 정답이 없으므로 어떤 정책이 실제 만족을 높이는지는 판단하지 않는다(Predictive Validity 미검증).** 아래 "점수"는 모두 ADR 기본 가중치로 다시 계산한 공통 지표이며, 우리 자체 점수다.

## 1. 독립 정답기 대비 (보조 경계)

정답기 `tests/oracle/scoring.py`는 별도 에이전트가 엔진 코드를 보지 않고 ADR만으로 작성했다(손계산·그리디 반례 포함 21개 시험).

- 무작위 150개 입력(4~10명, 제외 관계 0~2쌍, 이전 만남 0~2쌍, 정원 6~24, 최소 점수 0~70):
  - 독립 검증기 위반 **0건**
  - 정답기 최적값을 넘은 경우 **0건**
- 최적해와 비교:
  - 인원·품질 합·최저 점수까지 같은 경우 **142건**
  - 인원이 적은 경우 **1건**(국소 최적)
  - 인원이 같을 때 품질 합 차이는 **최대 5.01%**
- 최소 점수 0·제외 관계 없음일 때 기존 DP와 인원이 같은지 보는 무작위 12건은 모두 같았다. 회귀 기준일 뿐 최적성 증거가 아니다.

## 2. 운영사 가상데이터 실험

입력: 로컬 `data/우연한식탁_가상데이터.xlsx`의 응답 294개(성별: 남성 95, 여성 199). 개별 응답은 출력·기록하지 않는다.

실험용 가정:
- 출생연도 = 2026 − 나이. 나이 조건은 차이만 쓰므로 결과에 영향이 없다.
- 신청 순서 = 시트 행 순서. 원본에 타임스탬프가 없다.
- 지역별로 후보 묶음을 하나씩 만든다. 여러 지역을 고른 사람은 여러 묶음에 들어가므로 묶음 결과를 합산하지 않는다.
- 날짜는 연도가 없어 쓰지 않았다.
- 이전 만남 이력이 없어 '새로운 사람' 항목은 항상 100이다.

묶음 크기: 홍대 172, 을지로 75, 강남 73, 잠실 64. 홍대는 100명 목표를 넘는다.

확정 인원(성공률)과 평균/최저 테이블 점수:

| 조건 | 홍대 172 | 을지로 75 | 강남 73 | 잠실 64 |
|---|---|---|---|---|
| 기존 DP(점수 무시) | 172 (100%) 72.5/58.5 | 75 (100%) 72.9/62.5 | 73 (100%) 70.9/38.9 | 64 (100%) 70.8/57.2 |
| 최소 40 | 172 (100%) 73.3/58.5 | 75 (100%) 75.4/62.5 | 73 (100%) 74.6/41.8 | 64 (100%) 72.1/57.2 |
| 최소 50 | 172 (100%) 73.3/58.5 | 75 (100%) 75.4/62.5 | 72 (99%) 74.7/52.1 | 64 (100%) 72.1/57.2 |

- 기존 DP와 비교하면, 같은 인원에서 평균 점수가 0.8~3.8점 올랐다.
- 최소 50까지는 인원 손실이 최대 1명(강남)이다.
- 최소 70부터는 미매칭이 7~28명으로 급증한다. 최소 80은 성공률이 32~74%다.

### B. MBTI 모델 비교 (최소 50)

M0(모든 쌍 같은 점수), M1(100−5d, 기본), M2(100−10d) 모두 확정 인원이 같았다. 테이블 구성은 0~35% 바뀌었다. 평균 점수 차이는 대부분 모델 자체의 점수 수준 차이다. M0은 MBTI 항목이 100으로 고정되어 높게 나온다. 따라서 점수 크기를 모델 우열로 해석하지 않는다.

### D. 가중치 민감도 (한 항목씩 ×0.5 / ×1.5 후 재정규화, 최소 50)

- **확정 인원:** 거의 바뀌지 않았다(묶음별 0~2명).
- **테이블 구성:** 같은 테이블에 앉은 쌍 집합의 Jaccard 거리로 보면 0~82% 바뀌었다. 항목마다 실제 점수 차이가 작아 동점·근접 해가 많기 때문이다.
- **'새로운 사람' 가중치:** 이력이 없어 구성에 영향이 없었다(0%, 강남 22~28%는 재정규화에 따른 다른 항목 상대 비중 변화).

### E. 입력 순서 (최소 50, 시드 3개)

- **확정 인원:** 같았다.
- **테이블 구성:** 22~77% 바뀌었다. 결과는 같은 입력에서 결정적이지만, 동점을 신청 순서로 깨므로 순서가 바뀌면 구성도 크게 바뀐다.

### 항목별 실제 분포와 영향력 (최소 50 결과)

영향력 = 가중치 × 테이블 간 표준편차(점):

| 항목 | 가중치 | 표준편차 범위(4개 묶음) | 영향력 |
|---|---|---|---|
| 성비 | 0.20 | 30.3~31.6 | 6.1~6.3 |
| 연령대 | 0.25 | 14.3~23.7 | 3.6~5.9 |
| 관심사 | 0.15 | 8.4~12.2 | 1.3~1.8 |
| 희망 성향 | 0.10 | 6.0~8.8 | 0.6~0.9 |
| MBTI(M1) | 0.15 | 1.2~2.0 | 0.2~0.3 |
| 새로운 사람 | 0.15 | 0 | 0 |

## 3. 해석과 결정이 필요한 점

1. **실제 영향력 순서가 PRD 순서와 다르다.**
   - PRD 순서는 연령대 → 성비 → MBTI → 관심사 → 성향이다.
   - 실제 영향력은 성비 ≥ 연령대 > 관심사 > 성향 > MBTI다.
   - M1 MBTI는 80~100에 몰려 3순위인데도 영향이 사실상 동점 깨기 수준이다. 관심사만큼 영향을 주려면 가중치를 약 7배로 올려야 한다.
   - ADR과 사용자 조건에 따라 점수 폭을 인위적으로 늘리지 않았다. 따라서 "MBTI 영향이 작은 것"은 **현재 설정의 결과이며, 의도한 결과인지는 사용자 결정이 필요하다.** 선택지는 세 가지다.
     - (a) 유사도 근거가 약하므로 작게 둔다(현행).
     - (b) 가중치만 올린다.
     - (c) MBTI 모델을 바꾼다.
2. **최소 점수 운영값:** 이 데이터에서는 50~60이 인원 손실 2명 이하로 최저 점수를 끌어올린다. 70부터는 미매칭이 크게 늘어난다. 운영 적용 값은 사용자 재승인 사항이다.
3. **구성의 불안정성:** 인원은 안정적이지만 테이블 구성은 가중치·입력 순서에 민감하다. 실제 만족도 근거 없이 미세 조정하는 것은 의미가 작다.
4. **100명 초과 묶음:** 홍대 172명에서 일부 실행이 5초 상한에 도달했다. 100명 초과 입력의 처리 정책(U19)은 미정이다.
