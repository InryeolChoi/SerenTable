## 범위와 기준

2026-10-19. 위치: 개발·배포 기반 확보 → 핵심 데이터·화면·보안 설계(#15) → 공통 UI·핵심 화면 흐름 설계(#18)의 후속 검토. 새 Work/Task는 만들지 않았다. 제품 UI는 변경하지 않았다.

기준 main01deb3f. PR50은CI변경만포함하며모든검사성공·MERGEABLE이다. 이 문서의 UI 개선 구현·검증 완료와 구분한다. 운영 DB·배포 변경 없이 전용 로컬 PG17·합성 계정·8017포트에서 점검했다. Claude의 운영 인수·푸시·PWA 메타 작업은 수정하지 않았다.

기존 사용자 승인 검증 경계인 실제 API와 브라우저 외부 동작을 사용했다. `ui-flow-design.md`의 현재 화면 표시·44px 터치 기준을 적용했다. TDD 재현은 아직 RED이며 개선 구현을 통과한 것으로 표시하지 않는다.

- Chromium, Playwright WebKit 각각 참가자4화면(홈/프로필/일정신청/단체방)·운영자3화면(참가자/회차/운영현황)을13개뷰포트에서검토했다. 합계182조합.

- 두엔진모두 가로넘침0·pageerror0. 운영자는 합성4명목록, 참가자는 초기빈상태·폼이므로 가득찬채팅/긴식당주소/확정인원과운영예외대량데이터는이번범위가아니다.
- 344→744→390 크기 변경 뒤 미저장 표시명 유지 PASS. 물리힌지·화면분할·가상키보드·실제iPadSafari/PWA 실행을검증한결과는아니다.
- 인치는CSS폭을결정하지않는다. 위크기는대표시나리오이며특정모델의공식스펙이라고주장하지않는다. ‘아이폰듀오’는정확한모델을확정하지않고접힘/펼침폭의가정시나리오로만취급한다.

## 최소 개선 설계안

브랜드 근거를 유지한다. 색상은 바탕 `#FFF9ED`, 본문 `#422817`, 주색 `#8B4E27`, 보조 `#6A5847`, 경계 `#D7C6AF`, 선택/안내바탕 `#F4EADB`를 사용한다. 제공 자료에서 정한 재현 색상이며 새 공식브랜드로 주장하지 않는다.

글꼴은 기존한국어시스템sans본문16px를유지하고,명조는로고·화면주제목에사용한다. 본문왼쪽정렬,읽기폭약44rem·최대72ch,간격8/12/16/24/32px를기준으로한다. 버튼과주요이동의터치높이44px이상을유지한다.

```text
[우연한 식탁]                       [알림] [계정]
[내 식탁] [일정] [모임] [단체방] [더보기]
화면 제목
현재 상태와 다음 행동
해당 화면의 본문
보조 안내·정책 상세
```

기존시안은큰알림카드와길게나열한메뉴가모든화면에반복되어실제사용목적보다강하다. 수정안은로고·명조제목에서식탁초대장의성격을유지하고,정보위계는참가자의현재할일을중심으로잡는다. 장식·홍보히어로·새색상·모션을추가하지않는다. 전체서비스재설계가아닌공통틀보완을먼저수행한다.

## 후속 구현과 완료 기준

1. 현재 메뉴 표시/44px 기준의 RED를 브라우저회귀시험으로고정하고최소수정으로GREEN을확인한다.
2. 공통 알림 배치와 메뉴위계를개선한다. Claude의구독복원·해제/PWA작업과변경파일을확인한후통합한다.
3. 600/601 경계와744~834의운영자목록/상세를보완한다.
4. 동일뷰포트의전후캡처·두엔진넘침·입력보존·키보드이동을확인하고기존15개E2E를회귀실행한다. 실제기기키보드·회전·힌지·iPadSafari/PWA는별도인수로남긴다.
