# UI 브랜드 자료 대조

위치: 개발·배포 기반 확보 → 핵심 데이터·화면·보안 설계 → 공통 UI·핵심 화면 흐름 설계. Task #18 / PR #22의 보완 검토다. 2026-10-16 사용자 요청으로 확인했다.

## 결론

현재 스케치는 화면 흐름·상태·오류 검토용이며 **로고 직접 반영은 완료되지 않았다**. 명조 계열 글자와 따뜻한 분위기를 참고한 수준이다. 브랜드 적용 완료로 보고하거나 이 검토만으로 공식 로고를 새로 만들지 않는다. 이번 변경은 대조 결과 문서화이며 시안의 색·로고를 수정한 결과가 아니다.

## 직접 확인한 자료와 차이

원본은 docs/의 PDF 표지와 data/의 이미지다. 원본 파일과 PDF 표지 렌더링은 공개 저장소에 복제하지 않았다.

|---|---|---|---|
| docs/우연한식탁_CTO_온보딩오리엔테이션 (1).pdf, 1쪽 | 갈색·크림색 화면 예시, 둥근 식탁 주변 좌석 6개인 앱 아이콘 예시 | 버건디 주색, 텍스트 브랜드, 둥근 사각형 테이블 장식 | 직접 반영 안 됨. 표지의 예시는 공식 로고 원본 파일/브랜드 가이드와도 구별 |

위 경로는 읽기 쉽게 정규화한 이름이며 실제 제공 파일명은 Unicode 분해형일 수 있다. 현재 제공 이미지 3개와 PDF 표지에서 시각 근거를 확인했고 별도 서비스용 SVG/투명 로고·공식 색/글꼴 가이드는 확인하지 못했다. 따라서 PDF의 화면/아이콘 예시나 포스터를 공식 재사용 가능한 로고 파일로 단정하지 않는다.

## 기존 UI Task의 보완 기준

1. 서비스명 워드마크·식탁 아이콘과 운영사 표기를 구별하여 사용할 원본·위치를 정한다. 미제공 로고를 재현한 결과를 공식 원본이라고 표시하지 않는다.
2. 제공된 서비스 화면 예시의 갈색·크림색을 공통 색 검토의 우선 근거로 삼는다. 현재 `#783A46`은 임시 제안색으로 표시하고 원본에서 추출한 기준색이라고 하지 않는다.
3. 헤더·버튼·상태·단체방/운영자 화면에 일관되게 적용한 뒤 모바일/데스크톱에서 대비·잘림·가독성을 다시 확인한다.
4. 이미지에 포함된 사람 얼굴·운영사/서비스 이미지의 공개 사용 범위를 별도로 확인한다. 이번 검토에서 원본을 정적 자산으로 공개하거나 이미지 편집하지 않았다.

화면 흐름과 합성 시뮬레이션의 검토 결과는 유지한다. **흐름 설계 검토와 브랜드 적용 검토를 별개로 기록**하고 새 Work/Task를 추가하지 않는다. 제품 UI·배포 변경은 없다.
