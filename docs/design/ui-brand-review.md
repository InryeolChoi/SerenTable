# UI 브랜드 자료 대조

위치: 개발·배포 기반 확보 → 핵심 데이터·화면·보안 설계 → 공통 UI·핵심 화면 흐름 설계. Task #18 / PR #22의 보완 검토다. 2026-10-16 사용자 요청으로 확인했다.

## 결론

[공식 FAQ Q12](./official-faq-2026-10-16.md)의 유사 재현 허용에 따라 제공 자료를 다시 직접 확인하고 **갈색·크림색, 원형 6좌석 심볼, 두 줄 명조 워드마크를 재현 시안에 반영했다.** 서비스 심볼은 [직접 작성한 SVG](../prototypes/chance-table-symbol.svg), 글자는 로컬 명조 글꼴을 사용한다. [독립 UI 스케치](../prototypes/core-ui.html)의 헤더·버튼·선택 상태·단체방·운영자 화면에 같은 토큰을 적용했다.

이는 공식 로고 원본이나 브랜드 가이드를 수령한 결과가 아니다. 사진·얼굴·운영사 이미지와 PDF 표지를 공개 복제하지 않았다. 운영사 와썹하우스는 하단 텍스트로 구별했다. 원형 심볼의 여섯 좌석은 브랜드 표현이며 실제 참가 인원은 단체방 제목의 `4인 확정`으로 별도 표시한다. 제품 UI·배포와 실제 기능은 변경하지 않았다.

## 직접 확인한 자료와 이전 시안의 차이

원본은 docs/의 PDF 표지와 data/의 이미지다. 원본 파일과 PDF 표지 렌더링은 공개 저장소에 복제하지 않았다.

| 근거 | 확인한 시각 요소 | 보완 전 core-ui.html | 판정 |
|---|---|---|---|
| docs/우연한식탁_CTO_온보딩오리엔테이션 (1).pdf, 1쪽 | 갈색·크림색 화면 예시, 둥근 식탁 주변 좌석 6개인 앱 아이콘 예시 | 버건디 주색, 텍스트 브랜드, 둥근 사각형 테이블 장식 | 직접 반영 안 됨. 표지의 예시는 공식 로고 원본 파일/브랜드 가이드와도 구별 |
| data/우연한 식탁.jpg | 짙은 갈색 식사 사진, 크림색의 두 줄 명조 계열 ‘우연한 식탁’, 접시·식기 장식 | 로컬 명조 계열 한 줄 텍스트, 밝은 바탕 | 분위기/계열만 일부 참고. 워드마크 글자 모양·구성 동일하지 않음 |

| data/와썹하우스 로고2.jpg | 사진 위 운영사 워드마크 | 사용하지 않음 | 서비스 헤더 로고로 사용하지 않음 |

위 경로는 읽기 쉽게 정규화한 이름이며 실제 제공 파일명은 Unicode 분해형일 수 있다. 현재 제공 이미지 3개와 PDF 표지에서 시각 근거를 확인했고 별도 서비스용 SVG/투명 로고·공식 색/글꼴 가이드는 확인하지 못했다. 따라서 PDF의 화면/아이콘 예시나 포스터를 공식 재사용 가능한 로고 파일로 단정하지 않는다.

## 이번 보완과 확인 결과

- CTO 온보딩 PDF 1쪽을 로컬에서 렌더링하고 서비스 포스터 JPG를 열어 색감·원형 식탁·좌석·두 줄 제목 구성을 직접 확인했다. 원본과 렌더링은 저장소에 추가하지 않았다.
- 주색 `#8B4E27`, 바탕 `#FFF9ED`, 본문 `#422817`, 보조 `#6A5847`을 선택했다. 제공 자료에서 추출한 공식 기준색으로 주장하지 않는다. 버건디·사각 식탁 장식은 원형 심볼과 갈색 토큰으로 교체했다.
- 공식 FAQ의 1회권 9,900원, 멤버십 1/3/6개월 35,000/75,000/120,000원, 기간 내 참여 횟수 무제한을 표시했다. 매칭 실패 횟수에 따른 연장 원칙은 안내하되 연장 일수·기산점·자동 갱신을 임의로 정하지 않았다. 실제 결제·저장 없는 검토 배너와 결과 문구를 유지했다.
- Chrome headless(Puppeteer 제어), 360×1000·390×1000·1440×1000에서 신청/내 신청/실패 해결/단체방/피드백/운영자 6화면을 전환했다. 모든 화면의 `scrollWidth`는 viewport 폭과 같았고 SVG가 정상 로드됐으며 JavaScript 오류는 0건이었다.
- 세 폭에서 회차 미선택 오류·선택 후 6개월 멤버십 가격 요약·운영자 예외 상세/조치 안내·채팅의 HTML 미실행 텍스트 입력을 확인했다. 화면 전환·입력은 합성 시뮬레이션이며 서버 요청을 하지 않는다.
- 360px 신청, 390px 단체방, 1440px 운영자 전체 화면 스크린샷을 열어 제목·워드마크·버튼·긴 한국어 안내의 잘림과 읽기 순서를 육안 확인했다. 검토용 임시 캡처는 원본 자료와 마찬가지로 공개 자산에 넣지 않았다.
- 계산한 대비는 본문/바탕 **12.94:1**, 보조/바탕 **6.46:1**, 흰색 버튼 글자/갈색 **6.53:1**, 갈색/바탕 **6.23:1**, 보조/안내 바탕 **5.69:1**이다. 이 조합들은 일반 텍스트 4.5:1 기준을 넘는다. 실제 화면 전체의 접근성 인증을 의미하지 않는다.

**이 Task의 화면 흐름·브랜드 보완 설계 산출물은 검토 가능하다.** 최종 시각 디자인 승인, 실제 기기·스크린 리더 시험, 제품 인증/결제/채팅/API 보안·E2E 검증은 후속 기능 Work에서 수행한다. U03 연장 단위·U16 공개 정보 등 미정 정책은 해당 결정 이후 구체화한다. 새 Work/Task를 추가하지 않았다.

## 2026-10-18 제품 화면 적용 보완 (Work #7 · B 제공 브랜드 자료 적용)

브랜치 `claude/work8-brand`(기준 `claude/work8-feedback`). 위 재현 시안의 토큰을 제품 프런트엔드 전체에 일관되게 적용했다. 원본 사진·PDF 이미지·운영사 로고는 여전히 복제하지 않았고 재현물을 공식 원본으로 표시하지 않는다.

- **토큰화:** `frontend/src/style.css`의 하드코딩 색을 `:root` CSS 변수(`--color-bg/text/muted/primary/line/tint/error` 등)와 `--font-serif`로 바꿨다. 값은 기존 재현 토큰과 같으며 공식 기준색이 아니라는 주석을 남겼다.
- **누락 스타일 보완:** 화면에서 쓰지만 정의되지 않았던 `.panel`·`.pay-panel`·`.page-stack`을 정의했다. 흰 바탕 카드에 갈색 상단 선과 명조 소제목을 사용한다. 모임 안내·식당 배정·단체방·참가 이력·안전·노쇼 화면이 같은 카드 형식을 갖는다.
- **추가 화면:** 모임 안내의 식당명·지도 링크(44px 터치 영역), 단체방 메시지 목록(작성자 갈색·시각 보조색, 인라인 style 제거), 알림 패널(안내 바탕 카드, 상태/오류를 공통 `.notice` 형식으로, 빈 상태 보조 문구)에 className만 추가했다. 데이터 처리·라우팅 로직은 바꾸지 않았다.
- **페이지 메타:** `index.html`의 `theme-color`를 이전 파란색 `#175b80`에서 주색 `#8b4e27`로 바꾸고, 재현 심볼 SVG를 `frontend/public/favicon.svg`로 연결했다(주석으로 재현물임을 표시). 설명 메타와 `color-scheme: light`를 추가했다. 페이지 제목 `… · 우연한 식탁`은 기존 동작을 유지한다.
- **모바일:** 600px 이하에서 카드 안 단독 버튼은 전체 폭, 카드 여백은 16px로 줄였다. 긴 식당 주소·메시지는 `overflow-wrap: anywhere`로 줄바꿈한다.
- **대비(계산값):** 갈색/안내 바탕 5.48:1, 보조/흰 카드 6.77:1, 갈색/흰 카드 6.53:1, 오류/오류 바탕 7.74:1, 본문/안내 바탕 11.4:1로 일반 텍스트 4.5:1 기준을 넘는다.

검증: `npm ci && npm run build` 성공. 브라우저 렌더링·390px 수평 넘침·Playwright E2E는 이번에 실행하지 않았다(**미검증**). 남은 일은 실제 기기와 390px 화면에서의 육안 확인, 스크린 리더 확인, 최종 시각 디자인 승인이다. 푸시 알림 아이콘(`sw.js`)은 적용하지 않았다. PNG 앱 아이콘은 2026-10-19 추가(아래).


## 홈 화면 앱 이름·아이콘 (2026-10-19)

iPhone 홈 화면 앱이 페이지 제목("내 식탁 준비")과 글자 아이콘으로 표시되던 것을 고쳤다. 재현 심볼과 같은 도형으로 그린 180px PNG `frontend/public/apple-touch-icon.png`를 `/apple-touch-icon.png`로 제공하고, `apple-mobile-web-app-title`·`application-name`을 "우연한 식탁"으로 지정했다. 이미 추가된 홈 화면 앱은 삭제 후 다시 추가해야 새 이름·아이콘이 반영된다. 공식 로고 원본이 아닌 재현물이다.
