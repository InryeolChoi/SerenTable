# TypeScript 중심의 단일 앱으로 개발한다

최신 Q1 답변 “typescript 단일로 갈지, typescript + python으로 갈지 고민해보자”에 따라 언어 구성을 다시 비교한다. 현재 승인된 기술 구성은 없으며, 인터뷰 Q4 답변 후 결정과 근거를 기록한다. 아래는 기존 파일에 남아 있던 이력이며 최신 결정으로 사용하지 않는다.

개인 개발과 10월 20일 완성 목표를 고려해 참가자 모바일 웹과 운영자 어드민, 서버 기능을 TypeScript 중심의 단일 앱으로 구성한다. 별도 언어의 백엔드를 두면 실행 환경·API 연결·배포 검증이 늘어나므로 이번 MVP에서는 언어와 앱 구성을 통일하기로 했다. 프레임워크와 인프라 공급자, 백그라운드 작업 실행 위치는 후속 인터뷰에서 결정한다.

결정 근거: [인터뷰 Q1](../design/mvp-interview.md)의 사용자 답변 “typescript 중심의 단일 앱을 고안해보자. 시간이 많지 않아”.
