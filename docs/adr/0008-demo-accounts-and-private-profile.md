# 심사용 합성 계정과 제한된 소개를 제공한다

2026-10-16 사용자가 공개 가입 대신 사전 발급한 합성 참가자·운영자 계정만 제공하는 범위를 선택했다. Instagram은 필수 수집하되 다른 참가자에게 비공개로 유지한다. 확정된 동일 테이블에는 표시명·연령대·직업·MBTI·관심사만 소개하고 연락처·Instagram·정확한 출생연도·이름 원문을 자동 공개하지 않는 최소 공개안을 적용한다. 합성 계정도 실제 비밀번호 검증·세션·서버 권한을 사용하며 역할 선택으로 로그인을 대신하지 않는다.

일반 가입·SMS/OAuth·계정 복구와 실제 개인정보 모집 운영을 추가하는 대신 제한된 심사 흐름의 권한·동의·영속성을 검증한다. 이름은 프로필 원본, 표시명은 공개 소개용으로 구분한다. 심사 종료일·삭제 날짜는 제공되지 않았으므로 자동 폐기 시각이나 실제 개인정보의 장기 보관 정책을 확정하지 않는다. 합성 데모 정보만 사용하며 실제 운영 전의 보관·철회 정책은 U16에 남긴다.

## 2026-10-16 구현 검토 후 추가 결정

독립 Spec 검토에서 계약이 정하지 않은 세 가지를 사용자가 결정했다.

- 동의 이력은 목적별 변경을 서버에 보존하는 것으로 충족한다. 이력 열람 API·화면은 심사 흐름에 필요하지 않아 추가하지 않는다.
- 비밀번호 해시 동시 처리 한도 초과는 계정별 실패 잠금(429)과 구분해 503 `login_busy`로 응답한다. 올바른 자격 증명을 넣은 사용자에게 "시도가 많다"는 안내를 보이지 않기 위해서다.
- 참가자 프로필·동의 API는 참가자 전용이며 운영자는 403을 받는다. 매칭에 쓰이지 않는 운영자 프로필이 참가자 데이터에 섞이지 않게 권한 경계를 좁힌다.
