# ADR-0014: 체크인·피드백·신고와 다음 매칭 반영

- 상태: U08·U09·U15 사용자 승인(2026-10-18), 구현 진행 / 운영 미반영
- 범위: 모임 안내·피드백·재방문 → Work #8 참석·피드백·다음 추천
- 상세 계약: [feedback-contract.md](../design/feedback-contract.md)

## 결정

**U15 체크인:** 확정 참가자는 모임 시작 30분 전부터 종료 시각까지 앱에서 체크인한다. 종료 시각까지 체크인하지 않은 확정 참가자는 **노쇼 후보**다. 운영자가 확인해야 **확정 노쇼**가 되고, 사유가 있으면 면제로 기록한다. PRD §18의 "행사 후"는 피드백 작성 시점으로 해석한다(FDB-01 우선).

**U09 신고:** 신고가 접수되는 즉시 신고자와 피신고자 쌍을 향후 매칭에서 제외한다(PRD §15, 안전 우선). 운영자의 확정·기각은 경고·참가 제한·영구 제한 같은 제재(SAF-02)에만 영향을 준다. 기각돼도 쌍 분리는 유지한다. 이미 확정된 모임은 바꾸지 않는다. 신고 내용과 신고 사실은 피신고자에게 공개하지 않는다.

**U08 피드백 반영(규칙 기반 최소 반영):**
- '다시 만나고 싶지 않음'·차단·신고는 필수 제외 관계(H5)다.
- 서로 '다시 만나고 싶음'을 고른 쌍은 '새로운 사람' 점수에서 이전 만남으로 세지 않는다.
- 만족도·노쇼는 매칭 점수에 넣지 않는다. 확정 노쇼와 신고 확정은 운영자 제재로만 다룬다.
- 다음 일정 추천은 과거 테이블 평가가 높은 지역·요일의 모집 중 회차를 먼저 보이고, 추천 이유를 함께 표시한다.
- 피드백 미응답은 1회만 리마인드하며 재신청을 막지 않는다.

## 영향

스키마 0012는 새 표를 추가하고 `participant_exclusion.source`에 즉시 신고 `report`를 더한다. 기존 행은 바꾸지 않는다. 제외 관계와 피드백 저장은 한 트랜잭션에서 함께 커밋한다. 운영 반영과 마이그레이션은 별도 승인을 요구한다. 자동 가중치 학습(MAT-16, P2)은 범위 밖이다.
