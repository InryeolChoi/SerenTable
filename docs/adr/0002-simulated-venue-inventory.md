# 식당은 가상 재고에서 배정하고 재고 부족은 예외로 처리한다

심사용 MVP는 지역·시간·수용 인원을 갖춘 가상 식당 재고를 자동 배정하고 결과를 저장한다. 외부 식당 예약 API는 연동하지 않으며 실제 예약 완료를 주장하지 않는다. 배정 가능한 재고가 없으면 대체 식당을 탐색하고, 없을 때 운영자 예외로 남긴다.

킥오프 Q&A는 가상 식당 및 예약 가능 가정을 허용하고 식당 예약 실패 처리를 생략할 수 있다고 답했지만, PRD INF-02와 §15는 내부 재고 부족의 예외 처리를 요구한다. 외부 예약 실패와 내부 재고 부족을 구분해 구현 부담을 줄이면서 P0의 예외 흐름을 보존한다. 모든 실패를 생략하는 안과 실제 예약 API를 연결하는 안 대신 이 범위를 선택했다.
