# 원본 응답과 참가자 계정을 분리한 비공개 준비 영역

2026-10-17 사용자 승인: 원본 응답을 이름으로 병합하지 않고 각각 식별하며, 누락 연락처·Instagram·직업·출생연도·결제·동의를 만들지 않는다. 해석 가능한 선택만 정규화하고 불명확한 값은 검토 대상으로 남긴다. 원본을 앱 프로필·신청에 직접 넣으면 동일인과 결제·동의 사실을 잘못 만들 수 있으므로 별도 로컬 준비 DB의 JSONB/검토 코드와 원본 checksum·시트·행 계보를 사용한다.

원문 전체·가명·연락처·자유 입력은 복제하지 않고 로컬 원본을 재검토한다. 원본 관심사의 독서·글쓰기는 별도 통합 분류로 유지한다. 실제 앱 계정·회차·거래 생성, 운영 DB 적재, 과거 나이/날짜의 현재 일정 변환과 보관·삭제 기준은 후속이다. 현재 앱 역할이 DB 소유자인 점을 고려해 같은 DB의 schema만으로 격리됐다고 주장하지 않고 별도 연결을 사용한다.
