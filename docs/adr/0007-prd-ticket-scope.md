# 이용권은 현행 폼보다 PRD 요구를 우선한다

심사용 MVP의 이용권은 PRD APP-04에 따른 1회권과 모의 구독 이용권으로 구성한다. 실제 Google Forms의 3회권·잔여권 사용을 구독과 동일시하거나 추가 필수 상품으로 넣지 않는다. 이 결정 당시 구독 기간·이용 한도·갱신 규칙은 미정이었다. 이후 [2026-10-16 공식 FAQ Q4/Q5](../design/official-faq-2026-10-16.md)로 가격·1/3/6개월·기간 내 횟수 무제한·실패 시 기한 연장 원칙을 보완했다. 연장 세부 규칙·갱신 등은 U03에 남기며 실제 정기결제 연동을 승인한 결정은 아니다.

현행 운영을 재현하는 대신 P0 요구를 우선하고 상품별 만료·소비·환불 검증 범위가 늘어나는 것을 피한다. 근거: [인터뷰 Q14](../design/mvp-interview.md)의 사용자 답변 “PRD 우선”.
