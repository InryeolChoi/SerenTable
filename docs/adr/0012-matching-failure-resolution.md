# ADR-0012: 동일 신청의 실패 해결과 이용권 예약 이력

- 상태: 사용자 정책 승인, 구현·격리 검증 완료 / 운영 미반영 (2026-10-17)
- 근거: PRD PAY-03, STA-03~06, MAT-07~13; ADR-0011; matching-resolution-contract.md

## 결정

대안 이동은 동일 신청·원결제를 유지한다. 후보를 삭제하지 않고 종료·추가하며 실패 실행과 명시 동의·선택을 별도 해결 이력에 보존한다. 별도 자식 신청을 생성하는 대안은 원결제 연결·멱등 원신청 계약을 복잡하게 하므로 채택하지 않는다. 이동 동의 시각은 별도 기록하고 기존 신청 제출 시각순 우선순위는 유지한다.

미사용 1회권의 보관·재사용은 별도 권리 예약 이력으로 처리한다. 원결제나 원구매 신청을 덮어쓰지 않는다. 시스템 최종 실패의 미사용 1회권은 시간 제한 없이 전액 모의 환불한다. 실제 PG·일반 취소·부분 환불은 범위 밖이다. 멤버십은 최종 실패 신청당 기존 만료 시각 +7일을 한 번 적용하며 동일 신청의 이동·재시도에는 추가 연장하지 않는다. 금액 환불은 미정으로 보류한다. 이 세 사업 정책은 사용자 명시 승인을 받았다.

매칭 성공·오류 기록·실패 해결은 공통 PostgreSQL transaction advisory lock을 첫 잠금으로 사용한다. 서로 다른 회차의 Worker가 같은 사용자를 동시에 확정하는 기존 경쟁을 막는다. 사용자별 잠금을 뒤늦게 추가하는 대안은 기존 결제 잠금 순서와 교착 위험이 있고, DB 시간 구간 배제 제약은 별도 시간 스냅샷 모델이 필요하다. 소규모 MVP의 직렬화 비용을 수용한다. 운영 확대 시 재검토한다.

## 승인된 MVP 재배치 순서 예외

2026-10-17 사용자는 기존 U07의 **매칭 시각순**을 유지하고 PRD §7.4의 날짜·지역별 상대 우선순위와의 차이를 **명시적 MVP 예외**로 승인했다. 동의한 후보의 후속 처리는 기존 Worker가 이어가고, 선택 범위 밖 회차는 참가자의 명시 동의로만 이동한다. PRD 상대 우선순위까지 구현했다고 표시하지 않는다. 확정 시점 조정·전체 후보 조정기는 이번에 추가하지 않는다.

## 결과

추가 마이그레이션 0010과 상태·멱등·실제 PostgreSQL 경합 시험을 구현했다. 기존 확정과 구매 이력은 유지한다. 운영 반영에는 별도 승인이 필요하며 구형 API/Worker와 혼합 실행하지 않는다. ADR-0011의 점수·가중치는 변경하지 않는다.
